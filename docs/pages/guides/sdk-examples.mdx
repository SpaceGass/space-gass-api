This guide demonstrates a complete workflow using the generated SDK
clients: connect to the API, open a project, read structural data,
and close the project — with proper error handling.

## Full Workflow

<CodeTabs>
```csharp title="C#"
using SpaceGassApi;
using SpaceGassApi.Models;

// 1. Create the client
var client = SpaceGassApiClient.CreateClient();

try
{
    // 2. Open a project file
    await client.Job.Open.PostAsync(
        new OpenJobRequest
        {
            FilePath = @"C:\Projects\MyStructure.sg"
        });

    // 3. Get job information
    var job = await client.Job.GetAsync();
    Console.WriteLine($"Project: {job?.ProjectHeading}");
    Console.WriteLine($"Job:     {job?.Heading}");

    // 4. Get all nodes
    var nodes = await client.Job.Structure.Nodes.GetAsync();
    Console.WriteLine($"Found {nodes?.Count} nodes");

    foreach (var node in nodes)
    {
        Console.WriteLine(
            $"  Node {node.Key}: ({node.X}, {node.Y}, {node.Z})");
    }

    // 5. Close the project
    await client.Job.Close.PostAsync();
}
catch (Exception ex)
{
    Console.Error.WriteLine($"Error: {ex.Message}");
}
```

```python title="Python"
from extensions.client_extensions import create_client
from space_gass_api.models.open_job_request import OpenJobRequest

# 1. Create the client
client = create_client()

try:
    # 2. Open a project file
    await client.job.open.post(
        OpenJobRequest(file_path="C:\\Projects\\MyStructure.sg"))

    # 3. Get job information
    job = await client.job.get()
    print(f"Project: {job.project_heading}")
    print(f"Job:     {job.heading}")

    # 4. Get all nodes
    nodes = await client.job.structure.nodes.get()
    print(f"Found {len(nodes)} nodes")

    for node in nodes:
        print(f"  Node {node.key}: ({node.x}, {node.y}, {node.z})")

    # 5. Close the project
    await client.job.close.post()

except Exception as e:
    print(f"Error: {e}")
```
</CodeTabs>

## Filtering Nodes

<CodeTabs>
```csharp title="C#"
// Get nodes within a coordinate range
var filtered = await client.Job.Structure.Nodes.GetAsync(
    config =>
    {
        config.QueryParameters.MinX = 0;
        config.QueryParameters.MaxX = 100;
        config.QueryParameters.Limit = 50;
    });
```

```python title="Python"
# Get nodes within a coordinate range
filtered = await client.job.structure.nodes.get(
    request_configuration=lambda c: setattr(
        c.query_parameters, 'min_x', 0) or
        setattr(c.query_parameters, 'max_x', 100) or
        setattr(c.query_parameters, 'limit', 50))
```

```bash title="curl"
curl "http://localhost:5000/api/v1/job/structure/nodes?MinX=0&MaxX=100&Limit=50"
```
</CodeTabs>

## Querying Analysis Results

After running an analysis, you can query the results. Results use a columnar
format for efficient data transfer — grouped results return parallel arrays
rather than nested objects.

### Node Reactions

<CodeTabs>
```csharp title="C#"
// Get all node reactions
var result = await client.Job.Query.Analysis.Static.Node.Reactions.GetAsync();

foreach (var r in result.Results)
{
    Console.WriteLine($"Case {r.Case}, Node {r.Node}: " +
        $"Fx={r.Fx}, Fy={r.Fy}, Fz={r.Fz}");
}
```

```python title="Python"
# Get all node reactions
result = await client.job.query.analysis.static.node.reactions.get()

for r in result.results:
    print(f"Case {r.case_}, Node {r.node}: "
          f"Fx={r.fx}, Fy={r.fy}, Fz={r.fz}")
```

```bash title="curl"
curl http://localhost:5000/api/v1/job/query/analysis/static/node/reactions
```
</CodeTabs>

### Filtering by Load Case and Node

All query endpoints support optional filters via query parameters.

<CodeTabs>
```csharp title="C#"
// Get displacements for cases 1 and 3, nodes 10-12
var result = await client.Job.Query.Analysis.Static.Node.Displacements
    .GetAsync(config =>
    {
        config.QueryParameters.Case = [1, 3];
        config.QueryParameters.Node = [10, 11, 12];
    });
```

```python title="Python"
result = await client.job.query.analysis.static.node.displacements.get(
    request_configuration=lambda c: (
        setattr(c.query_parameters, 'case_', [1, 3]),
        setattr(c.query_parameters, 'node', [10, 11, 12])
    ))
```

```bash title="curl"
curl "http://localhost:5000/api/v1/job/query/analysis/static/node/displacements?case=1&case=3&node=10&node=11&node=12"
```
</CodeTabs>

### Member Intermediate Forces (Columnar Format)

Grouped results like member forces use a columnar layout — the parent object
contains the case and member keys, with force values as parallel arrays
indexed by station.

<CodeTabs>
```csharp title="C#"
var result = await client.Job.Query.Analysis.Static.Member.IntermediateForces
    .GetAsync(config =>
    {
        config.QueryParameters.Member = [1];
    });

foreach (var m in result.Results)
{
    Console.WriteLine($"Case {m.Case}, Member {m.Member}:");
    for (int i = 0; i < m.Station.Length; i++)
    {
        Console.WriteLine($"  Station {m.Station[i]}: " +
            $"Fx={m.Fx[i]}, Fy={m.Fy[i]}, Mz={m.Mz[i]}");
    }
}
```

```python title="Python"
result = await client.job.query.analysis.static.member.intermediate_forces.get(
    request_configuration=lambda c:
        setattr(c.query_parameters, 'member', [1]))

for m in result.results:
    print(f"Case {m.case_}, Member {m.member}:")
    for i in range(len(m.station)):
        print(f"  Station {m.station[i]}: "
              f"Fx={m.fx[i]}, Fy={m.fy[i]}, Mz={m.mz[i]}")
```

```bash title="curl"
curl "http://localhost:5000/api/v1/job/query/analysis/static/member/intermediate-forces?member=1"
```
</CodeTabs>

### Pagination

All query endpoints support `offset` and `limit` for pagination.

<CodeTabs>
```csharp title="C#"
// Get the first 100 node displacements
var page1 = await client.Job.Query.Analysis.Static.Node.Displacements
    .GetAsync(config =>
    {
        config.QueryParameters.Offset = 0;
        config.QueryParameters.Limit = 100;
    });

// Get the next 100
var page2 = await client.Job.Query.Analysis.Static.Node.Displacements
    .GetAsync(config =>
    {
        config.QueryParameters.Offset = 100;
        config.QueryParameters.Limit = 100;
    });
```

```python title="Python"
page1 = await client.job.query.analysis.static.node.displacements.get(
    request_configuration=lambda c: (
        setattr(c.query_parameters, 'offset', 0),
        setattr(c.query_parameters, 'limit', 100)
    ))

page2 = await client.job.query.analysis.static.node.displacements.get(
    request_configuration=lambda c: (
        setattr(c.query_parameters, 'offset', 100),
        setattr(c.query_parameters, 'limit', 100)
    ))
```

```bash title="curl"
# Page 1
curl "http://localhost:5000/api/v1/job/query/analysis/static/node/displacements?offset=0&limit=100"

# Page 2
curl "http://localhost:5000/api/v1/job/query/analysis/static/node/displacements?offset=100&limit=100"
```
</CodeTabs>
