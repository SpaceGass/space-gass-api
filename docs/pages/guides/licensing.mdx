This repository uses a **dual-license** strategy to be
developer-friendly while protecting the SPACE GASS API definition.

## At a Glance

| Content | License | What it means |
|---|---|---|
| SDK clients and examples (`sdks/`) | **MIT** | Use, modify, and distribute freely with no restrictions |
| OpenAPI specifications (`descriptions/`) | **CC BY-ND 4.0** | Free to use and reference, but you may not distribute modified versions |

## MIT License — SDKs and Examples

The generated SDK clients, hand-crafted examples, and sandbox scripts
are all licensed under the [MIT License](https://github.com/Spacegass/space-gass-api/blob/develop/LICENSE).
This gives you full freedom to:

- Use the SDK in commercial and open-source projects
- Modify the code to suit your needs
- Redistribute it with your own applications

No attribution is required, though it is appreciated.

## CC BY-ND 4.0 — OpenAPI Specifications

The OpenAPI specification files that define the API are licensed under
[Creative Commons Attribution-NoDerivatives 4.0](https://github.com/Spacegass/space-gass-api/blob/develop/LICENSE-SPEC).
This means you may:

- **Use** the specifications to generate your own client code,
  build integrations, and reference the API structure
- **Share** the specifications with others

But you **may not** create modified or derivative versions of the
specification files and distribute them.

## Why Dual Licensing?

The OpenAPI spec is the authoritative definition of the SPACE GASS API.
Licensing it under CC BY-ND ensures a single, consistent API
definition exists, while the permissive MIT license on the SDKs means
engineering firms and developers have zero friction when integrating
the API into their own tools and workflows.

## Summary

If you are using the SDK to build integrations with SPACE GASS, the
MIT license covers everything you need. The CC BY-ND license only
applies to the specification files themselves — not to any code you
write against the API.
