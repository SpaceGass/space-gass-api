# Contributing to space-gass-api

Thank you for your interest in contributing to the SPACE GASS API ecosystem!

## Repository Layout

| Path | Description | Editable? |
|---|---|---|
| `descriptions/` | OpenAPI specifications (CC BY-ND 4.0) | Spacegass team only |
| `sdks/*/client/` | Auto-generated SDK clients | No — regenerated by Kiota |
| `sdks/*/examples/` | Hand-crafted SDK examples (MIT) | Yes — contributions welcome |
| `sandbox/` | Informal scripts and experiments (MIT) | Yes — contributions welcome |
| `docs/` | Developer documentation site | Yes — contributions welcome |

## How to Contribute

### Examples and Sandbox Scripts

1. Fork this repository
2. Create a feature branch from `develop`
3. Add your example in the appropriate `sdks/*/examples/` directory, or create a new folder under `sandbox/`
4. Ensure your example includes a README explaining what it demonstrates
5. Open a Pull Request against `develop`

### Documentation

1. Fork this repository
2. Edit or add MDX pages under `docs/pages/`
3. Test locally with `cd docs && npm run dev`
4. Open a Pull Request against `develop`

### Bug Reports and Feature Requests

Please [open an issue](https://github.com/spacegass/space-gass-api/issues/new) with as much detail as possible.

## What We Cannot Accept

- **Modifications to OpenAPI specs** (`descriptions/`) — these are maintained exclusively by the Spacegass team and are licensed under CC BY-ND 4.0.
- **Hand-edits to generated SDK code** (`sdks/*/client/`) — these folders are overwritten on every Kiota generation run. If you find a bug in the generated code, please open an issue referencing the spec.

## Code of Conduct

Please be respectful and constructive in all interactions. We are committed to providing a welcoming and inclusive experience for everyone.
